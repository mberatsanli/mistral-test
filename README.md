# Oyunlar 🎮

Tek dosyalık, tarayıcıda çalışan piksel oyunlar — kurulum yok, internet yok.

## Nasıl oynanır?

Dosyayı indir (bu sayfadaki `oyunlar/` klasörüne tıkla → dosya → sağ tık → "Farklı kaydet")
veya repoyu indir (`Code → Download ZIP`), sonra `.html` dosyasına çift tıkla — tarayıcıda açılır.

## Oyunlar

- **🐍 Yılan** — `oyunlar/snake.html`
  Ok tuşları veya WASD ile oyna. Elmaları topla, duvarlara çarpma. Skorun artınca hızlanır.
- **📞 Gizli Telefon** — `oyunlar/gizli-telefon.html`
  Adam telefonda konuşup sigara içerken kız arkadaşını yakalatma!
  `Boşluk` basılı tut = saklan 🤫 · Bırak = konuş ve skor kazan.
  Kız arkadaş dönerken `!` uyarısı gelir — o an saklanmazsan yakalanırsın 😱

Rekorlar tarayıcında saklanır (localStorage).
